# ESP32 OBD2 Data Logger & Telegram Mini App

Цей репозиторій містить повний набір коду для створення власного OBD-II логера на базі ESP32 з передачею даних на сервер та відображенням їх у Telegram Mini App.

## Структура проекту

- `esp32-obd2/` — Прошивка для мікроконтролера ESP32 (PlatformIO).
- `esp32-obd2-backend/` — Серверна частина (Node.js + SQLite) та Frontend-дашборд (HTML/JS + Chart.js).

---

## 1. Як завантажити код на ESP32?

Прошивка написана з використанням фреймворку Arduino, але налаштована для середовища **PlatformIO**, яке набагато зручніше для складних проектів.

**Кроки для прошивки:**
1. Завантажте та встановіть [Visual Studio Code](https://code.visualstudio.com/).
2. Відкрийте VS Code, перейдіть у розділ розширень (Extensions) і знайдіть **PlatformIO IDE**. Встановіть його.
3. У VS Code виберіть `File -> Open Folder...` і відкрийте папку `esp32-obd2` з цього репозиторію.
4. Дочекайтеся, поки PlatformIO ініціалізує проект і завантажить необхідні бібліотеки (ELMduino, ArduinoJson).
5. Відкрийте файл `src/main.cpp` та змініть налаштування під себе (WiFi SSID, пароль, IP сервера).
6. Підключіть ESP32 до комп'ютера через USB кабель.
7. На нижній панелі VS Code (або в меню PlatformIO зліва) натисніть кнопку **Upload** (іконка стрілочки вправо `→`).
8. Прошивка скомпілюється і автоматично завантажиться на плату!

## 2. Чи треба MAC адресу ELM 327 десь прописувати?

**Ні, не обов'язково!** 
У нашому коді в `main.cpp` з'єднання відбувається за іменем пристрою (найчастіший спосіб):

```cpp
ELM_PORT.connect("OBDII"); // Підключення за іменем
```

Більшість адаптерів ELM327 мають ім'я `"OBDII"`. Якщо ваш адаптер називається інакше, вам потрібно лише змінити це ім'я в коді.

**Альтернативний спосіб (за MAC-адресою):**
Якщо підключення за іменем не працює або у вас в машині багато Bluetooth пристроїв з однаковим іменем, ви можете прописати MAC-адресу.
У коді є закоментована/невикористана змінна `address`. Ви можете ввести туди MAC-адресу вашого адаптера (її можна подивитись в налаштуваннях Bluetooth на телефоні, підключившись до адаптера) і змінити рядок підключення на:

```cpp
uint8_t address[6] = {0x11, 0x22, 0x33, 0x44, 0x55, 0x66}; // Ваш MAC
ELM_PORT.connect(address);
```

## 3. Запуск сервера

1. Перейдіть до папки сервера: `cd esp32-obd2-backend`
2. Встановіть залежності: `npm install`
3. Запустіть сервер: `npm start` (або `node server.js`)

Не забудьте створити файл `.env` з `TELEGRAM_BOT_TOKEN=ваш_токен`, якщо хочете використовувати Telegram бота.
