# ESP32 OBD2 Data Logger & Telegram Mini App 🚗📊⛽

Повний комплект коду для автономного OBD-II логера на базі **ESP32**, який збирає телеметрію вашого авто через Bluetooth ELM327, підтримує **офлайн-накопичення поїздок без інтернету**, відправляє дані на власнаний Node.js backend через HTTPS/Ngrok та надає стильний **Telegram Mini App** із детальною аналітикою поїздок, розрахунком витрати й вартості палива, а також моніторингом цін на АЗС України.

---

## 🌟 Основні можливості системи

- **📡 Live-Телеметрія:** відображення швидкості (км/год), обертів двигуна (RPM), температури охолоджуючої рідини (°C), напруги бортової мережі (В) та розходу палива (л/год) у реальному часі.
- **📱 Telegram Mini App (Web App):** адаптивний графічний інтерфейс із темною темами, лінійними графіками Chart.js та трьома основними вкладками: `Live`, `Архів поїздок`, `Ціни АЗС`.
- **📴 Офлайн-накопичення (Offline Buffering):** якщо під час їзди точка доступу на телефоні вимкнена, ESP32 зчитує показання й зберігає до **1800 точок (~30 хвилин руху)** у RAM. При увімкненні Wi-Fi плата автоматично синхронізує весь масив через `POST /api/obd/batch`.
- **🗺️ Автоматичний Архів Поїздок (Trips Archive):**
  - Автоматичне групування сесій їзди в окремі поїздки.
  - Розрахунок пройденої дистанції (км), тривалості, середньої та максимальної швидкості.
  - Детальний перегляд графіків швидкості й обертів кожної окремої поїздки в модальному вікні.
- **💰 Паливна аналітика та витрата:**
  - Розрахунок спаленого бензину в літрах за поїздку (на основі MAF/Fuel Rate або розрахункового 7.5л/100км).
  - Середній розхід на 100 км (`л/100км`).
  - Поле введення власної ціни бензину А-95 (`грн/л`) з автоперерахунком вартості кожної поїздки в гривнях (`₴`).
- **⛽ Моніторинг цін на АЗС України (А-95):**
  - Пряме інтегроване відстеження цін на звичайний бензин А-95 у мережах:
    - 🟢 **OKKO**
    - 🟢 **WOG** (прямий API `api.wog.ua`)
    - 🔵 **UPG** (прямий аналіз `upg.ua`)
    - 🟡 **KLO**
    - 🔷 **UKRNAFTA**
  - Автоматичне фонове оновлення цін кожні 4 години + кнопка «🎯 Застосувати ціну» для миттєвої установки ціни обраної АЗС у розрахунки.

## 📁 Структура репозиторію

- `esp32-obd2/` — Прошивка для мікроконтролера ESP32 (PlatformIO).
  - `src/main.cpp` — Логіка зчитування ELM327, неблокуючий Wi-Fi, офлайн-буферизація та відправка.
  - `platformio.ini` — Налаштування PlatformIO з підтримкою `huge_app.csv` для розширеного розміру прошивки.
- `esp32-obd2-backend/` — Серверна частина та Веб-інтерфейс.
  - `server.js` — Node.js + Express API + SQLite (база даних поїздок, парсер цін АЗС WOG/UPG/Minfin).
  - `public/index.html` — Telegram WebApp інтерфейс (Live графіки, Архів, Ціни АЗС).
  - `public/index.css` — Стильний дизайн у стилі Glassmorphism.
  - `docker-compose.yml` & `Dockerfile` — Контейнеризація для легкого деплою на Linux / Home Assistant.

## ⚙️ 1. Налаштування та прошивка ESP32

Прошивка написана для середовища **PlatformIO** (VS Code).

> [!IMPORTANT]
> **Таблиця розділів `huge_app.csv`:**  
> Оскільки прошивка одночасно використовує `BluetoothSerial` (для ELM327) та `WiFiClientSecure` (для HTTPS/Ngrok), стандартного розміру програми ESP32 (1.3 МБ) не вистачає. В `platformio.ini` додано параметр `board_build.partitions = huge_app.csv`, який виділяє під програму 3.1 МБ.

### Кроки для прошивки:
1. Встановіть [Visual Studio Code](https://code.visualstudio.com/) та розширення **PlatformIO IDE**.
2. Відкрийте папку `esp32-obd2` у VS Code.
3. Перевірте та відредагуйте `src/main.cpp`:
   ```cpp
   const char* ssid = "Pajero";           // Назва точки доступу (Pajero)
   const char* password = "090384wifi";   // Пароль точки доступу
   const char* serverUrlBase = "https://ваш-ngrok-домен.ngrok-free.dev/api/obd";
   ```
4. Підключіть ESP32 через USB-кабель до ПК.
5. Натисніть кнопку **Upload** (стрілочка `→` внизу VS Code) для компіляції та завантаження.

### Bluetooth з'єднання з ELM327:
За замовчуванням у коді вказана пряма MAC-адреса вашого OBD2 сканера `00:00:00:33:33:33` з PIN-кодом `"1234"` для миттєвого підключення без затримок:
```cpp
uint8_t elmMac[6] = {0x00, 0x00, 0x00, 0x33, 0x33, 0x33};
```

## 🚀 2. Деплой Сервера (Home Assistant / Docker / Node.js)

### Спосіб А: Як Home Assistant Add-on (Рекомендовано для Home Assistant) 🏠

1. Скопіюйте папку `ha-addon/esp32-obd2` у директорію `/addons/` на сервері вашого Home Assistant (через Samba Share, SSH або Studio Code Server).
2. У Home Assistant відкрийте: **Налаштування** ➡️ **Додатки** ➡️ **Магазин додатків** ➡️ натисніть `⋮` (вгорі праворуч) ➡️ **Оновити**.
3. У розділі **Локальні додатки** оберіть **ESP32 OBD2 Telemetry & WebApp** та натисніть **Встановити**.
4. У вкладці **Конфігурація** вкажіть ваш `telegram_bot_token` (за потреби) та натисніть **Запустити**.
5. Увімкніть **Показувати на бічній панелі**, щоб відкривати дашборд прямо в меню Home Assistant (через Ingress)!
6. Детальніша інструкція та конфігурація сенсорів для `configuration.yaml` — у файлі [`DOCS.md`](file:///C:/Users/Oleksandr/.gemini/antigravity-ide/scratch/esp32-obd/ha-addon/esp32-obd2/DOCS.md).

### Спосіб Б: Через Docker Compose

База даних `obd_data.db` зберігається у Docker Volume (`obd_db_data`), тому дані зберігаються навіть при оновленні контейнера.

1. Перейдіть у папку бекенду:
   ```bash
   cd esp32-obd2-backend
   ```
2. (За потреби) відредагуйте `docker-compose.yml` та вкажіть змінні оточення `TELEGRAM_BOT_TOKEN`.
3. Запустіть контейнер:
   ```bash
   docker-compose up -d --build
   ```
4. Перевірте статус логів:
   ```bash
   docker logs -f esp32-obd2-backend
   ```

### Спосіб В: Локальний запуск (Node.js)

1. Перейдіть до папки: `cd esp32-obd2-backend`
2. Встановіть залежності: `npm install`
3. Створіть `.env` файл:
   ```env
   PORT=3000
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   ```
4. Запустіть сервер: `npm start`

## 📊 4. REST API Ендпоінти

- `POST /api/obd` — приймає один запис телеметрії від ESP32.
- `POST /api/obd/batch` — приймає масив офлайн-записів `[{rpm, speed, temp, voltage, fuel_rate, dt}, ...]`.
- `GET /api/data` — повертає останні показання та поточну активну поїздку.
- `GET /api/history` — повертає лог останніх 60 точок для live-графіків.
- `GET /api/trips` — список усіх поїздок із розрахованою дистанцією, розходом та вартістю.
- `GET /api/trips/:id` — детальні записи конкретної поїздки для модального вікна.
- `DELETE /api/trips/:id` — видалення поїздки з архіву.
- `POST /api/trips/finish` — примусове завершення поточної сесії.
- `GET /api/fuel-prices` — отримати актуальні ціни АЗС (OKKO, WOG, UPG, KLO, UKRNAFTA).
- `POST /api/fuel-prices/refresh` — примусово оновити ціни АЗС.
- `GET /api/settings` / `POST /api/settings` — отримати/зберегти ціну бензину А-95.
