# Changelog 📋

Усі помітні зміни у проекті **ESP32 OBD2 Data Logger & Home Assistant Add-on** документуються у цьому файлі.

---

## [1.1.1] - 2026-09-14
### 🐛 Виправлено
- Виправлено автентифікацію Ngrok (`ERR_NGROK_4018`): пряма передача прапорця `--authtoken` та змінної середовища у команду `ngrok http`.
- Додано автоматичне очищення URL домену від префіксів `https://` / `http://` та зайвих пробілів.

## [1.1.0] - 2026-09-14
### ✨ Нові функції
- Додано **вбудовану підтримку Ngrok** прямо в Home Assistant Add-on.
- Автоматичний фоновий запуск тунелю зі статичним доменом за параметрами `ngrok_authtoken` та `ngrok_domain`.
- Повне усунення помилки `ERR_NGROK_3200` — тепер тунель працює 24/7 автономно на сервері Home Assistant.

## [1.0.4] - 2026-09-14
### ⚡ Змінено
- Спрощено вікно конфігурації Home Assistant Add-on: вилучено параметр `fuel_price` зі схеми налаштувань.
- Керування ціною пального повністю перенесено у веб-інтерфейс дашборду (автовибір із цін АЗС або ручне введення).
- Встановлено актуальний базовий дефолт ціни А-95 (58.50 грн/л).

## [1.0.3] - 2026-09-14
### 📝 Документація & Безпека
- Повністю оновлено та розширено документацію (`DOCS.md` та `README.md`).
- Додано готові шаблони REST-сенсорів для `configuration.yaml` Home Assistant.
- Додано готові картки для Lovelace Dashboard (Gauge та Entities) та готові автоматизації (розряд АКБ, перегрів).
- Усі персональні дані (Wi-Fi, паролі, назви авто) замінено на універсальні демо-значення.

## [1.0.2] - 2026-09-14
### 🐛 Виправлено
- Виправлено помилку збірки `403 Forbidden`: перехід на офіційні базові образи `ghcr.io/home-assistant/{arch}-base:latest`.
- Додано надійне встановлення `nodejs`, `npm` та компіляторів `python3 make g++` через пакетний менеджер Alpine Linux (`apk add`).

## [1.0.1] - 2026-09-14
### 🐛 Виправлено
- Додано відсутні пакети `npm` та `nodejs` у Dockerfile збірки Home Assistant.

## [1.0.0] - 2026-09-14
### ✨ Початковий реліз Home Assistant Add-on
- Створено офіційний маніфест репозиторію аддонів Home Assistant (`repository.yaml`).
- Додано підтримку Home Assistant Ingress (дашборд у бічному меню HA).
- Забезпечено збереження SQLite бази даних у персистентному розділі `/data/obd_data.db`.
- Інтеграція Telegram-бота та веб-додатка з Live-графіками та архівом поїздок.
- Автоматичний парсер цін А-95 на АЗС (OKKO, WOG, UPG, KLO, Ukrnafta).
