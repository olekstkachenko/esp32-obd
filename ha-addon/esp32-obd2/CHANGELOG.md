# Changelog 📋

Усі помітні зміни у проекті **ESP32 OBD2 Data Logger & Home Assistant Add-on** документуються у цьому файлі.

---

## [1.2.6] - 2026-09-15
### 📱 Мобільна Адаптація Навігації
- **CSS Grid Navigation:** меню переведено на 4-колонкову адаптивну сітку, що запобігає переповненню та обрізанню кнопок на смартфонах.
- **Cache-Busting:** додано автоматичне оновлення кешу стилів (`v=1.2.6`).

## [1.2.4] - 2026-09-15
### 📡 Виправлено надсилання логів & Нова вкладка Діагностики
- **mbedTLS RAM Optimization:** виправлено виділення пам'яті для HTTPS (`client.setBufferSizes(2048, 1024)`), що усунуло помилку нестачі оперативної пам'яті (Out of Memory) під час одночасної роботи Bluetooth та Wi-Fi.
- **🛠️ Вкладка «Діагностика ESP32»:** додано повнорозмірну консоль логів у реальному часі та картки стану пристрою (IP, Wi-Fi RSSI, статус Bluetooth OBD2, вільна RAM).
- **💓 Heartbeat Ping:** додано регулярне опитування стану пристрою кожні 10 секунд для точного відображення Онлайн/Офлайн статусу у веб-панелі.
- **Ngrok Interstitial Bypass:** додано заголовок `ngrok-skip-browser-warning` у запити ESP32 для безперешкодної передачі даних на безкоштовні Ngrok-домени.

## [1.2.3] - 2026-09-14
### 🔒 Безпека та Конфіденційність
- **Secrets Management:** винесено Wi-Fi паролі, адресу сервера та параметри Bluetooth у локальний файл `secrets.h`.
- **Git Security:** додано правила у `.gitignore`, що повністю виключають потрапляння персональних облікових даних у публічний GitHub-репозиторій.
- **Шаблон налаштувань:** створено безпечний приклад `secrets.example.h` для швидкого налаштування іншими користувачами.

## [1.2.2] - 2026-09-14
### 🎨 UI & Брендінг Add-on
- **Офіційна іконка та логотип:** додано фірмову графіку (`icon.png`, `logo.png`) для відображення картки аддону в офіційному Home Assistant Add-on Store та списку встановлених додатків.
- **Сумісність компіляції ESP32:** остаточно виправлено виклики бібліотеки `ELMduino` (`nb_rx_state`, `ELM_BUFFER_OVERFLOW`) для стабільної збірки у PlatformIO.

## [1.2.1] - 2026-09-14
### 🛠️ Надійність зчитування OBD2 & Діагностика
- **ELM327 Error Decoding:** додано детальне розшифрування кодів помилок ELM327 (`NO_RESPONSE`, `UNABLE_TO_CONNECT`, `TIMEOUT`, `GARBAGE_DATA`) з відправкою статусів у веб-консоль діагностики.
- **Auto-Recovery Protocol:** автоматичне виявлення серії збоїв (15 невдалих спроб) та автоматичний перезапуск узгодження протоколу з ЕБУ авто.
- **Extended Timeout:** збільшено таймаут відповіді до 3000 мс для повільних автомобільних шин.

## [1.2.0] - 2026-09-14
### ⚡ Оптимізація та Рефакторинг
- **SQLite Database:** увімкнено WAL-режим (`PRAGMA journal_mode=WAL`), синхронізацію `NORMAL`, кешування та додано індекси (`idx_obd_records_trip_id`, `idx_obd_records_timestamp`, `idx_trips_status`) для миттєвої обробки мільйонів точок.
- **Async/Await Promisification:** переведено роботу бази даних на нативні проміси (`getAsync`, `allAsync`, `runAsync`), усунено вкладені колбеки у сервісах та контролерах.
- **ESP32 Firmware Memory:** додано пре-алокацію пам'яті (`vector.reserve` та `String.reserve`) для запобігання фрагментації оперативної пам'яті (RAM Heap) при тривалих поїздках.
- **Frontend Lifecycle Optimization:** автоматична зупинка фонового опитування (`polling`) при перемиканні на вкладки «Архів» та «Ціни АЗС» для зниження навантаження на процесор та мережу.

## [1.1.1] - 2026-09-14

## [1.1.0] - 2026-09-14
### ✨ Нові функції

- Повне усунення помилки `ERR_NGROK_3200` — тепер тунель працює 24/7 автономно на сервері Home Assistant.
