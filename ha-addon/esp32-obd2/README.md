Автономний комплекс для збору, аналізу та візуалізації телеметрії вашого автомобіля в **Home Assistant** та **Telegram Mini App** на базі мікроконтролера **ESP32** і адаптера **ELM327 Bluetooth**.

---

## 🌟 Ключові можливості

| Модуль | Опис можливостей |
|---|---|
| **🖥️ Home Assistant Ingress** | Повноцінний інтерактивний веб-дашборд доступний прямо в бічному меню Home Assistant без необхідності відкривати окремі вкладки чи порти. |
| **📡 Live-Телеметрія** | Відображення в реальному часі: швидкість (км/год), оберти двигуна (RPM), температура ОР (°C), напруга бортової мережі (В) та розхід палива (л/год). |
| **📴 Офлайн-буферизація** | Якщо телефон вимкнено або немає зв'язку, ESP32 зберігає до **1800 записів (~30 хвилин їзди)** у пам'яті RAM і автоматично синхронізує їх при появі Wi-Fi. |
| **🗺️ Автоматичний журнал поїздок** | Автоматична фіксація старту й зупинки авто, розрахунок пройденої дистанції (км), тривалості, середньої та максимальної швидкості з детальними графіками кожної поїздки. |
| **💰 Паливна аналітика** | Точний розрахунок спаленого пального (в літрах), середньої витрати (`л/100км`) та вартості поїздки у гривнях (`₴`). |
| **⛽ Моніторинг цін АЗС України** | Вбудований парсер актуальних цін бензину А-95 на АЗС **WOG, UPG, OKKO, KLO, UKRNAFTA** з можливістю застосувати ціну в один клік. |
| **🤖 Telegram Bot & Mini App** | Сповіщення про завершені поїздки та стильний адаптивний мобільний інтерфейс (Glassmorphism + Dark Mode). |
| **🏠 Сенсори Home Assistant** | Можливість створення REST-сенсорів у Home Assistant для автоматизацій (контроль стану акумулятора, захист від перегріву тощо). |

## 🏗️ Архітектура системи

```
[ Автомобіль (OBD-II Port) ]
            │
      (Bluetooth)
            ▼
[ Сканер ELM327 Bluetooth ]
            │
      (Bluetooth Master)
            ▼
[ Мікроконтролер ESP32 ] ──(Офлайн-буфер RAM)
            │
       (Wi-Fi / HTTPS)
            ▼
[ Home Assistant Add-on: ESP32-OBD2 ]
   ├── Express REST API
   ├── База даних SQLite (/data/obd_data.db)
   ├── Ingress UI (Бічна панель HA)
   ├── Парсер цін АЗС (WOG, UPG, OKKO, KLO, Ukrnafta)
   └── Telegram Bot Notification Service
```

## ⚙️ Швидкий старт

1. **Встановіть додаток** у Home Assistant через **Add-on Store** ➡️ **ESP32 OBD2 Add-ons** ➡️ **Install**.
2. Відкрийте вкладку **Конфігурація (Configuration)**:
   - Вкажіть токен вашого бота `telegram_bot_token` (за бажанням).
   - Вкажіть бажану базову ціну пального `fuel_price`.
3. Увімкніть перемикач **Показувати на бічній панелі** та натисніть **Запустити (Start)**.
4. Натисніть **OBD2 Tracker** у лівому меню Home Assistant!
